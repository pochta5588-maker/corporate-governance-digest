# Corporate Governance Digest — дайджест новостей по корпоративному управлению

Квартальный дайджест новостей по корпоративному управлению в России: сервис на базе Claude Code (агента) и Python-скриптов, который собирает новости из официальных источников, раскладывает их по тематическим разделам и собирает итог в готовый к передаче Word-документ (.docx) — в обычном или акцентном оформлении.

## Проблема

Сотрудники корпоративных служб — корпоративные секретари, юристы по корпоративному праву, члены советов директоров — должны быть в курсе быстро меняющегося регулирования и практики:

- законодательство по АО и ООО меняется постоянно (новые ФЗ, поправки в законы об АО 208-ФЗ и ООО 14-ФЗ);
- Банк России выпускает письма, разъяснения и проекты в области корпоративного управления, рынок ценных бумаг и раскрытие информации регулируются в том же потоке новостей;
- важные судебные решения по корпоративным спорам появляются еженедельно и сразу влияют на практику;
- все это рассеяно по десяткам несистематизированных источников, а чтение их вручную занимает часы.

Дайджест решает задачу: **раз в квартал за несколько минут получать структурированную сводку только существенных событий со ссылками на первоисточники** — без рекламы, слухов и нерелевантных новостей.

## Пользователь

Проект создан для корпоративных юристов и корпоративного секретаря акционерных обществ (публичных и непубличных) и обществ с ограниченной ответственностью:

- корпоративные секретари АО и ООО — главный пользователь, готовит сводку для совета директоров;
- члены советов директоров (включая независимых) и корпоративных комитетов;
- юристы корпоративной практики в юридических департаментах и в консалтинге;
- юристы и специалисты по корпоративному управлению обществ с госучастием, эмитентов ценных бумаг и институтов коллективного инвестирования.

## Основная функция

Сервис работает в два этапа:

**1. Сбор и структурирование новостей (агент, скилл `q-news`).** Claude-агент по описанной в скилле методике:

- уточняет период (по умолчанию — текущий квартал);
- опрашивает обязательные источники: Банк России (cbr.ru), КонсультантПлюс, Гарант, Frank Media, Интерфакс, РБК, Forbes — и дополнительные: РИД, АНД, Spencer Stuart, Московская биржа, Госдума, Минфин, Верховный Суд РФ, B1, ТеДо и др.;
- фильтрует по тематическому отбору: законодательство (АО/ООО), законодательные инициативы, новости и нормативные акты ЦБ, рынок ценных бумаг (эмиссия, листинг/делистинг), раскрытие информации, санкционное законодательство, судебная практика, исследования консалтинговых компаний;
- раскладывает новости по фиксированной структуре из 7 разделов:
  1. Новости законодательства
  2. Законодательные инициативы
  3. Новости Банка России
  4. Новости рынка ценных бумаг
  5. Раскрытие информации
  6. Правоприменительная практика (судебная практика)
  7. Исследования
- для каждой новости пишет короткий заголовок, описание на 3–5 предложений (суть, кого затрагивает, чем важно), дату и кликабельную ссылку на первоисточник (можно до 2 ссылок);
- пишет итог в Markdown-файл, например `digest_q3_2026_v2.md`.

**2. Сборка Word-документа (Python-скрипты).** Скрипт читает Markdown-файл и собирает из него готовый .docx: заголовки разделов, параграфы, маркированные списки, **жирный** текст и кликабельные гиперссылки. Два варианта сборки:

- `build_docx.py` — нейтральное оформление: Times New Roman 12 pt, межстрочный интервал 1.15, стандартные поля.
- `build_docx_styled.py` — акцентное оформление: Times New Roman 12 pt с межстрочным интервалом 1.15 в тексте, Arial в заголовках, оранжевые линии-подчёркивания и маркеры новостей, тёмно-серые заголовки, колонтитулы с названием дайджеста и номером страницы; гиперссылки синим.

## Формат результата

Пользователь получает **редактируемый Word-файл (.docx)**, сохранённый в папку по кварталу (например, `3 квартал-новости/`), с полным названием вида `Дайджест_корпоративное_управление_Q3_2026.docx`:

- документ с фиксированной структурой из 7 тематических разделов;
- внутри раздела новости идут в хронологическом порядке;
- каждая новость: заголовок, описание 3–5 предложений, дата, 1–2 кликабельных ссылки на первоисточники;
- оформление готово к прямой отправке совету директоров или публикации без доработки;
- параллельно сохраняется исходник в Markdown — его удобно править и перегенерировать документ повторной сборкой.

Параллельно агент отчитывается пользователю, какие источники проверены, а какие недоступны.

## Технологии

- **Язык программирования:** Python 3 (скрипты сборки Word-документа).
- **Библиотеки Python:** [`python-docx`](https://python-docx.readthedocs.io/) — сборка .docx; стандартная библиотека (`re`, `sys`).
- **Агент и скилл:** Claude Code, скилл в формате Markdown-скиллов Claude (`.claude/skills/q-news/digest-corporate-governance.md`) — описывает методику сбора новостей, источники, фильтры, структуру и формат.
- **Форматы данных:** исходник дайджеста — Markdown (подмножество: `#`/`##`/`###` заголовки, `- ` маркированные списки, `**жирный**`, `[текст](ссылка)`); результат — .docx (Word 2007+, openxml); логотип — PNG.
- **Система контроля версий:** git + GitHub (`gh` CLI).

## Как пользоваться

1. Установите Python 3 и библиотеку для сборки Word:

   ```bash
   pip install python-docx
   ```

2. Запустите скилл в Claude Code:

   ```
   /q-news дайджест Q3 2026
   ```

   Агент соберёт новости, запишет Markdown-файл (например, `digest_q3_2026.md`) в текущую папку.

3. Соберите Word-документ по исходнику:

   ```bash
   # нейтральное оформление
   python3 build_docx.py digest_q3_2026.md digest_q3_2026.docx

   # акцентное оформление (колонтитулы, оранжевые акценты)
   python3 build_docx_styled.py digest_q3_2026.md digest_q3_2026.docx
   ```
